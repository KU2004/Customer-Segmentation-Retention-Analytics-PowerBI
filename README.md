# 🚀 Customer Segmentation & Retention Analytics (Power BI)

## 📌 Project Overview
This project focuses on analyzing customer behavior, segmenting customers based on value, and identifying retention patterns using Power BI.

The dashboard helps businesses understand:
- Which customers generate the most revenue
- Which customers are at risk of churn
- How to improve customer retention strategies

---

## 🎯 Objective
To build a business-focused analytics dashboard that enables data-driven decision-making for marketing, CRM, and growth teams.

---

## 🛠 Tools & Technologies
- Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Excel (Dataset)

---

## 📊 Dataset Description
The dataset contains 100+ customer records with:
- Demographics (Age, Gender, City)
- Purchase behavior (Frequency, AOV, Total Spend)
- Customer segmentation (High, Mid, Low Value)
- Retention status (Retained, At Risk, Churned)
- Engagement and satisfaction scores

---

## 🔄 Data Preparation (Power Query)
- Removed null values and duplicates
- Changed data types (dates, numbers)
- Created Month & Year columns
- Cleaned and formatted dataset for analysis

---

## 📐 Key DAX Measures
- Total Customers
- Total Revenue
- Average Order Value (AOV)
- Retention Rate %
- Churn Rate %
- Customer Lifetime Value (CLV)
- Segment-wise Revenue
- Average Engagement Score

## 💡 Key Insights
- High-value customers contribute the majority of revenue
- A significant portion of customers are at risk of churn
- Online channel performs best in terms of revenue
- Gold-tier customers show highest retention and AOV
- Engagement score strongly correlates with customer spending
